기존에 구현한 **ON BOARD 무역 시뮬레이터 MVP의 UI/UX를 전면적으로 디자인 개선해줘.**

이번 작업의 목적은 새로운 기능을 추가하는 것이 아니라, 현재 구현된 기능을 **하나의 완성도 높은 서비스처럼 보이도록 UI/UX를 개선하는 것**이다.

---

# 1. ON BOARD의 디자인 콘셉트

서비스 이름:

**ON BOARD**

서비스 성격:

> International Trade Simulation

핵심 카피:

> **무역거래에 직접 올라타다.**

ON BOARD는 사용자가 한국 수출기업의 무역 담당자가 되어 실제 무역거래와 유사한 의사결정을 경험하는 시뮬레이션 서비스다.

따라서 일반적인 교육 사이트처럼 보이면 안 된다.

다음 세 가지 느낌을 결합한다.

### ① Global Trade

국제무역, 선박, 컨테이너, 항로, 국가 간 거래

### ② Business Dashboard

전문적인 기업용 서비스, 데이터, 비용, 거래정보

### ③ Simulation Game

단계별 진행, 선택, 결과, 점수, 리스크

전체적인 인상은:

> **“실제 무역회사의 디지털 거래 플랫폼을 게임처럼 체험하는 서비스”**

가 되어야 한다.

* 알록달록한 교육 플랫폼

# 4. 타이포그래피

전체적으로 현대적인 Sans-serif 폰트를 사용한다.

가능하다면:

**Inter**

를 기본 영문 폰트로 사용한다.

한국어는 시스템 Sans-serif를 사용한다.

제목은 굵고 명확하게.

본문은 가독성을 우선한다.

숫자와 금액은 일반 텍스트보다 조금 더 강조한다.

예:

TOTAL COST

₩87,475,400

여기서 숫자가 시각적으로 가장 먼저 들어오도록 한다.

# 6. Home 화면 UI

Home은 가장 인상적인 화면으로 만든다.

전체 화면을 단순한 랜딩페이지처럼 구성하지 말고,

**“무역 거래를 시작하기 위한 Control Center”**

느낌으로 만든다.

상단에는 작게:

TRADE SIMULATION PLATFORM

그 아래 큰 제목:

# 무역거래에 직접 올라타다.

설명:

가상의 국제무역 거래를 직접 진행하며
계약부터 운송, 결제, 보험, 환율까지 경험해보세요.

CTA:

**START NEW TRADE →**

CTA는 화면에서 가장 명확하게 보여야 한다.

# 7. Home의 Visual Hero

Hero 영역 오른쪽에는 무역을 연상시키는 시각 요소를 배치한다.

실제 이미지가 없으면 CSS와 Lucide 아이콘을 이용해 간단한 그래픽을 만든다.

예:

🇰🇷 BUSAN

──────────────→

🚢

──────────────→

🇺🇸 LOS ANGELES

단순한 국가 아이콘 나열이 아니라,

**GLOBAL TRADE ROUTE**

라는 느낌이 들도록 디자인한다.

지도 전체를 구현할 필요는 없다.

얇은 선과 점, 항로 느낌의 그래픽만 사용한다.

# 8. 거래 정보 카드

KOREA → USA

AUTOMOTIVE PARTS

USD 100,000

# 9. Simulation 화면

거래를 시작하면 화면의 목적이 완전히 바뀐다.

사용자가 “지금 내가 무엇을 해야 하는가?”를 한눈에 이해할 수 있어야 한다.

상단에는 진행률을 표시한다.

예:

01 CONTRACT
02 INCOTERMS
03 SHIPPING
04 PAYMENT
05 INSURANCE
06 FX
07 COST
08 RESULT

현재 단계는 Navy 또는 Blue로 강조한다.

완료된 단계는 체크 표시.

미완료 단계는 회색.

# 26. 반응형

Desktop뿐 아니라 모바일에서도 자연스럽게 작동해야 한다.

Desktop:

2-column layout

Mobile:

1-column layout

으로 변경한다.

Option Card도 모바일에서 한 줄에 하나씩 표시한다.

금액과 결과가 모바일 화면을 넘어가지 않도록 한다.

---

# 27. Animation

애니메이션은 최소한으로 사용한다.

허용:

* Step transition
* Card hover
* Selected state
* Progress transition
* Number count-up
* Result reveal

금지:

* 과도한 bounce
* 과도한 zoom
* 지속적으로 움직이는 배경
* 게임처럼 화려한 particle effect

전체적으로 **금융/물류 서비스 수준의 절제된 애니메이션**을 사용한다.

# 31. 최종 디자인 목표

최종 결과물을 봤을 때 다음과 같은 느낌이 들어야 한다.

> “무역을 공부하는 사이트”

가 아니라

> **“실제 글로벌 무역 플랫폼을 게임처럼 체험하는 서비스”**

처럼 보여야 한다.

동시에 대학생이 만든 포트폴리오 프로젝트라는 느낌보다,

**실제 스타트업에서 만든 MVP 서비스**

처럼 보이도록 완성도를 높여줘.

기존에 구현된 기능과 계산 로직은 유지한다.

UI 개선 과정에서 기능을 임의로 삭제하거나 동작을 변경하지 않는다.

먼저 현재 프로젝트의 컴포넌트와 화면 구조를 분석한 뒤,
중복되는 UI를 공통 컴포넌트로 정리하고,
일관된 디자인 시스템을 적용한다.

마지막으로 모든 화면을 직접 확인하여 다음을 점검한다.

* 정렬
* 여백
* 폰트 크기
* 색상
* 버튼 상태
* 선택 상태
* 경고 상태
* 모바일 반응형
* 화면 간 디자인 일관성

**단순히 CSS를 조금 수정하는 수준이 아니라 ON BOARD라는 하나의 브랜드가 모든 화면에서 일관되게 느껴지도록 UI/UX를 리디자인해줘.**
